2. A solução

Desenvolver um sistema web de vendas utilizando PHP com Laravel, estruturado de forma escalável, permitindo inicialmente:

Cadastro de mercadorias;
Cadastro de fornecedores;
Cadastro de usuários;
Controle de cargos e permissões;
Registro de vendas;
Consulta de vendas realizadas;
Relatórios gerenciais;
Controle básico de estoque;
Estrutura preparada para expansão futura para um ERP.

A ideia é começar como um sistema de vendas, mas já pensar na arquitetura de forma modular, para futuramente adicionar módulos como financeiro, fiscal, compras, contas a pagar, contas a receber e emissão de documentos.
